# Console RPG "Journey"

Консольная RPG на C++ с боем, инвентарём, картой и сохранением.

## Возможности
- Пошаговая боевая система
- Инвентарь (оружие, еда, зелья)
- Карта 3x5 с врагами и предметами
- Сохранение / загрузка прогресса
- Счётчик убийств

## Сборка и запуск

### Требования
- Компилятор с поддержкой C++11 (g++, MinGW, MSVC)
- Make (опционально)

### Сборка через Makefile
```bash
make
./game.exe
```
# Управление
WASD — движение по карте

1 (атака), 2 (инвентарь), 3 (защита) — в бою

Q — выход (прогресс не сохраняется)
# Структура проекта
Game.cpp — главный цикл

Player / Enemy / Character — боевая система

Inventory / Item / Weapon / Potion / Food — предметы и инвентарь

Map / Location — карта и локации

Combat — боевая логика

ItemFactory — создание предметов
# Сохранение
Данные сохраняются в save.txt при нажатии S в игре.
